Pengaturan Pembatalan (Cancel Lock & Timer)

Pengaturan untuk langsung membuka tombol cancel tanpa menunggu 20 menit dari penyedia.

Aktifkan agar tombol "Batal / Cancel" selalu terbuka langsung sejak detik ke-0 (Tanpa harus menunggu 20 menit).

Default 20 menit sesuai dengan masa aktif pendaftaran SMS provider.

Sistem akan memanggil API pembatalan secara otomatis jika waktu hitung mundur habis dan OTP belum masuk.
